# 🧠 C++ Coding Interview Bootcamp (14 Days)

## 🎯 Goal

Build **pattern recognition, speed, and confidence** for C++ coding interviews.

---

## 📌 Rules

* ⏱️ 25–35 min per problem
* 🗣️ Talk out loud while solving
* 🔁 If stuck >15 min → look at solution → re-code
* ✅ A problem is “learned” only if you can redo it from memory

---

## 🔁 Daily Structure

1. **Memory Problem (15–20 min)** — no help
2. **2–3 New Problems (30 min each)**
3. **Quick Review (10–15 min)**

   * What pattern?
   * What trick?
   * What did I miss?

---

# 🗓️ Week 1 — Core Patterns

## ✅ Day 1 — Arrays + Hashing

* [X] Two Sum
  👉 Find two indices whose values add to a target

  ```cpp
  vector<int> twoSum(vector<int>& nums, int target);
  ```

  ⚠️ unordered_map (value → index)

* [X] Contains Duplicate
  👉 Check if any number appears more than once

  ```cpp
  bool containsDuplicate(vector<int>& nums);
  ```

  ⚠️ unordered_set

* [X] Valid Anagram
  👉 Check if two strings have same character counts

  ```cpp
  bool isAnagram(string s, string t);
  ```

  ⚠️ frequency count

**Next Day Memory:** Two Sum

## ✅ Day 2 — Hashing

**From Memory:**

* [X] Two Sum

**New:**

* [X] Intersection of Two Arrays
  👉 Return unique elements present in both arrays

  ```cpp

  ```

  ⚠️ use set

* [X] Top K Frequent Elements
  👉 Return the k most frequent numbers


  ⚠️ hashmap + bucket sort or heap

* [X] Product of Array Except Self
  👉 For each index, return product of all other elements

  ```cpp

  ```

  ⚠️ prefix + suffix (no division)

# 🧠 Pattern Triggers (Read Daily)

* Hashing → map/set
* Two pointers → sorted / pairs
* Sliding window → substring / subarray
* Stack → matching / undo
* Linked list → pointer manipulation
* Binary search → sorted search space
* Tree DFS → recursion
* Tree BFS → queue
* Backtracking → choices
* Intervals → sort first
* DP → reuse previous results
